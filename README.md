# Bleach Dash

Current Bleach Dash browser game source.

## Structure
- `index.html` — main game
- `assets/` — game artwork, audio, sprites, and other runtime assets
- `_check.js` — project/runtime checks
- `supabase-config.js` — Supabase configuration used by the game
- `supabase_schema.sql` — database schema
- `SUPABASE_MIGRATION_EXISTING_PROFILES.sql` — existing-profile migration
- `ICHIGO_MASTER_ATLAS.json` — Ichigo asset/animation data
- `test_boss_harness.html` — development/testing harness

## Important
This repository intentionally excludes old update notes, historical backups, and obsolete duplicate project folders. The original project should be kept separately as an archive.
